# OmniNotice: Testing Case

Демонстрационный проект с артефактами тестирования для внутреннего сервиса уведомлений. 
Репозиторий содержит изолированную «песочницу» с реальными компонентами и 12 автотестами, которые можно запустить локально.

## 🎯 Контекст
В рамках задачи по разработке «Журнала рассылок push-уведомлений» (React + TypeScript + Chakra UI) было необходимо:
1. Провести ручное тестирование интерфейса.
2. Провести код-ревью компонентов.
3. Покрыть критический функционал автотестами (Vitest + React Testing Library).
4. Задокументировать найденные баги.

## 🚀 Как запустить
Проект полностью автономен. Чтобы увидеть зеленые тесты, выполните:

```bash
npm install
npm run test

🐛 Найденные баги (в ходе тестирования)
Мобильная верстка: Таблица не имеет горизонтального скролла (overflow-x), из-за чего на узких экранах колонки обрезаются. Фильтры не переносятся на новую строку.

Логика пагинации при раскрытии строки: В оригинальном коде страницы при клике на строку массив данных подменялся на 1–2 элемента, что ломало пагинацию. В песочнице этот баг исправлен (используется currentData).

Хардкод данных: В деталях рассылки захардкожены «Инициатор», «Процент прочтения» и «Ошибки». Требуется интеграция с API.
